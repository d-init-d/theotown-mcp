# TheoTown MCP v0.2.0

TheoTown MCP v0.2.0 is the first release intended for day-to-day city automation. It replaces fragile dynamic-Lua handoff behavior with a durable JSON protocol, adds live city diagnostics, and packages the Python server together with the in-game plugin for repeatable installation.

## Highlights

### Durable protocol-v2 IPC

- Uses a static in-game Lua engine and a JSON mailbox instead of generating executable Lua for every request.
- Protects concurrent writers with a cross-process lock and same-directory atomic replacement.
- Binds jobs to the active city session and rejects expired, replayed, or cross-city work.
- Supports queued, running, completed, failed, cancelled, and cancel-requested states.
- Limits the queue to 64 jobs, each plan to 250 commands and 10,000 affected tiles.
- Processes at most 16 work units per 100 ms tick to keep the simulation responsive.

### Live city diagnostics

`theotown_get_status` and `theotown://city/status` now expose:

- Treasury, monthly income, population by wealth level, jobs, residential capacity, taxes, date, speed, and map dimensions.
- Overall happiness and category-level values for healthcare, education, police, fire protection, parks, transport, supply, waste, taxes, and environment.
- Counts for buildings, roads, zones, pipes, wires, vehicles, power plants, water facilities, medical services, police, fire services, schools, parks, and waste facilities.
- Estimated power and water production, consumption, reserve, utilization, and adequacy.
- Sampled service coverage with representative weak coordinates for healthcare, police, fire, education, parks, and waste collection.
- Representative locations for illness, abandonment, waste, dead bodies, fire, and missing road access.

Diagnostics refresh every 10 seconds and sample at most 512 RCI buildings for spatial coverage, limiting their impact on game performance.

### Verified in-game construction

- Uses current official TheoTown draft IDs and Builder/Tile signatures.
- Supports roads, zones, buildings, demolition, pipes, wires, simulation speed, plan validation, job polling, and cancellation.
- Reports bounded, coordinate-aware errors with aggregate counts instead of returning unbounded failure payloads.
- Returns game rejections accurately when terrain, water, occupancy, funds, or draft constraints prevent construction.

### Distribution and compatibility

- Ships `plugin.json`, `core.lua`, and `inbox.lua` inside the Python wheel.
- Adds non-destructive plugin installation with optional backups.
- Supports Windows 10/11 and Python 3.10, 3.11, and 3.12.
- CI runs linting, 433 automated tests, and wheel construction across all supported Python versions.

## Install

Download `theotown_mcp-0.2.0-py3-none-any.whl` from this release and follow the [human or AI-agent installation guide](https://github.com/d-init-d/theotown-mcp#2-prerequisites--installation).

For an upgrade from an earlier development build:

```powershell
$McpHome = Join-Path $env:USERPROFILE ".theotown-mcp"
& "$McpHome\Scripts\python.exe" -m pip install --upgrade ".\theotown_mcp-0.2.0-py3-none-any.whl"
& "$McpHome\Scripts\theotown-mcp.exe" install-plugin --force --backup
& "$McpHome\Scripts\theotown-mcp.exe" probe-ipc
```

Restart TheoTown once after installing or upgrading the plugin, then open a city. A healthy status response has `connected: true`, `protocol: 2`, and `diagnostics_error: null`.

## Upgrade notes

- Protocol v2 is not wire-compatible with the earlier dynamic-Lua development bridge. Upgrade the Python package and in-game plugin together.
- Existing city saves are not modified by the installer.
- Runtime telemetry, queued requests, and job-result files are preserved during installation.
- Pending jobs created by a different city session are rejected rather than replayed.

## Validation

- 433 local tests passed.
- Python 3.10 compatibility was additionally exercised locally.
- GitHub Actions passed on Python 3.10, 3.11, and 3.12.
- Wheel contents and the installed in-game plugin were verified by SHA-256.

## Known constraints

- The packaged installer currently targets TheoTown desktop on Windows.
- TheoTown must be running with a city open before construction commands can be accepted.
- Utility balance and spatial coverage are diagnostic estimates derived from public Lua APIs; the game remains authoritative for final placement and simulation outcomes.
